# 1. Objetivo deste documento

Este documento representa o contexto operacional oficial para a Equipe de Engenharia do Project-Victory.

Ele existe para permitir continuidade de desenvolvimento entre diferentes sessões de trabalho, chats ou integrantes, sem depender do histórico de conversas anteriores.

Este documento não substitui:

- contratos técnicos;
- código fonte;
- documentação arquitetural oficial.

Ele funciona como ponto inicial de contexto para execução dos Work Items aprovados.

---

# 2. Organização das responsabilidades

## Arquitetura

Responsável por:

- Definir arquitetura.
- Criar e validar contratos técnicos.
- Aprovar escopo de implementação.
- Resolver conflitos arquiteturais.
- Validar entregas da Engenharia.

A Arquitetura é a fonte de decisão arquitetural.

---

## Equipe de Engenharia

Responsável por:

- Implementar contratos aprovados.
- Preservar arquitetura existente.
- Entregar código funcional.
- Executar validações técnicas.
- Registrar alterações no Git.

A Engenharia não cria decisões arquiteturais.

---

# 3. Regra principal de implementação

A Engenharia deve implementar somente o que estiver explicitamente definido em um contrato aprovado pela Arquitetura.
