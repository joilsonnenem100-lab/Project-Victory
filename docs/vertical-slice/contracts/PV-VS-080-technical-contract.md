# PV-VS-080 — Technical Contract

## Nome

Validar Múltiplos Efeitos no Character

---

# Objetivo Técnico

Permitir que o Aggregate Character valide uma solicitação contendo múltiplos efeitos evolutivos antes da aplicação.

---

# Decisões Arquiteturais

A validação pertence exclusivamente ao Character.
