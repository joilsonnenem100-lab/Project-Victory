# PV-VS-026 — Technical Contract

## Nome

Gerar Resolução Técnica do Combate

---

# Objetivo

Permitir que um resultado técnico de ação de combate seja processado dentro do contexto Combat, gerando uma resolução técnica para continuidade dos próximos fluxos.

---

# Escopo

Implementar exclusivamente:

- receber resultado técnico de ação de combate;
- validar CombatContext associado;
- validar resultado de ação existente;
- gerar resolução técnica;
- retornar resultado da resolução.
