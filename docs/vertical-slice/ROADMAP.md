# Project-Victory
# Vertical Slice Roadmap

Status: OFFICIAL
Owner: Product Owner + Technical Director

---

# Objetivo

O objetivo deste roadmap é conduzir o desenvolvimento do Vertical Slice do Project-Victory até a validação do Core Gameplay Loop.

Este roadmap representa exclusivamente a execução do Vertical Slice.

Ele não substitui o ROADMAP oficial do projeto.

---

# Regras

- O roadmap é dividido por fases.
- Cada fase é composta por Milestones.
- Cada Milestone deve gerar uma build executável.
- Nenhuma Milestone pode ficar mais de 3 dias úteis sem entregar algo jogável.
- Funcionalidades fora do objetivo da fase permanecem no backlog.
- Alterações neste roadmap somente são permitidas em casos críticos aprovados pelo Product Owner.

---

# FASE 0 — ACCOUNT SYSTEM

Objetivo:

Permitir que um jogador crie uma conta e entre no jogo.

Milestones

M0.1
- Criar Conta

M0.2
- Login

M0.3
- Entrar no jogo

---

# Critério de Conclusão

O First Fun será considerado concluído quando um jogador conseguir:

- Entrar no jogo.
- Preparar uma Hunt.
- Executar uma Hunt.
- Receber Loot.
- Receber Experiência.
- Evoluir seu personagem.
- Iniciar espontaneamente uma nova Hunt.
