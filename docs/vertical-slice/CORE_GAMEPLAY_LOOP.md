# Project-Victory
# Core Gameplay Loop

Status: OFFICIAL

---

# Objetivo

Definir o ciclo principal de gameplay que será validado pelo Vertical Slice.

Todo o desenvolvimento do Vertical Slice deverá contribuir diretamente para este ciclo.

---

# Core Gameplay Loop

Entrar no jogo

↓

Preparar Hunt

↓

Executar Hunt

↓

Receber Resultado

↓

Evoluir Character

↓

Preparar Nova Hunt

↓

Executar Nova Hunt

---

# Objetivo do Vertical Slice

Validar que este ciclo é suficientemente divertido para motivar o jogador a executá-lo repetidamente.

---

# Critério de Sucesso

O Vertical Slice será considerado bem-sucedido quando um jogador concluir uma Hunt e desejar iniciar outra espontaneamente.

---

# Prioridade

Durante o Vertical Slice, qualquer funcionalidade deverá responder positivamente à pergunta:

"Esta funcionalidade melhora o Core Gameplay Loop?"

Caso a resposta seja negativa, ela deverá ser adiada para uma fase posterior do projeto.

---

# Fora do Escopo

Não fazem parte do Core Gameplay Loop do Vertical Slice:

- PvP
- Guild
- Marketplace
- Craft
- Eventos
- Sistema Social
- Casas
- Ranking
- Conteúdo Endgame

---

# Regra

A simplicidade possui prioridade sobre a quantidade de funcionalidades.

O Vertical Slice existe para validar o gameplay, não para validar conteúdo.
