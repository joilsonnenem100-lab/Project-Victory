# Project-Victory
# Monster Specification

Status: OFFICIAL

---

# Objetivo

Definir o comportamento do primeiro monstro utilizado no Vertical Slice.

Este documento descreve apenas o comportamento esperado durante a Primeira Hunt.

---

# Quantidade

A Primeira Hunt utilizará apenas um tipo de monstro.

---

# Objetivo

Validar o Core Gameplay Loop.

Não estamos validando variedade de conteúdo.

---

# Comportamento

O monstro:

- Ataca automaticamente.
- Recebe dano automaticamente.
- Pode vencer ou perder o combate.
- Pode conceder experiência.
- Pode conceder loot.
- Pode conceder ouro.

---

# Resultado Esperado

Ao término da Hunt o monstro deverá estar em um dos estados:

- Derrotado
- Sobreviveu ao combate

---

# Balanceamento

O balanceamento definitivo não faz parte do Vertical Slice.

O único objetivo é permitir validar o Core Gameplay Loop.

---

# Fora do Escopo

Não fazem parte deste documento:

- IA avançada.
- Habilidades especiais.
- Elementos.
- Resistências.
- Bosses.
- Grupos de monstros.
- Spawn.
- Respawn.
- Variações de comportamento.

---

# Critério de Sucesso

O comportamento do monstro deve ser suficiente para validar uma Hunt completa.
