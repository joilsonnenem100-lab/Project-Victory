# PV-VS-027 — Aplicar Resultado de Combate

Status: Planned

Fase: FASE 4 — Combat Flow Inicial

Milestone: M3.4 — Aplicação de Resultado de Combate Validada

---

# Objetivo

Adicionar ao Vertical Slice a capacidade de aplicar um resultado de combate ao contexto de combate ativo.

---

# Capacidade Entregue

Um resultado de combate gerado corretamente pode ser aplicado ao fluxo de combate mantendo o estado consistente.

---

# Critério de Aceite

- Um Combat Result válido pode ser aplicado.
- O Combat Context é atualizado corretamente.
- Resultados inválidos são rejeitados.
- A aplicação do resultado não altera sistemas fora do escopo.
- O Character permanece sem alterações diretas neste contrato.
- Nenhuma mecânica avançada de combate é implementada.
