# PV-VS-032 — Encaminhar Resultado da Hunt para Reward

Status: Planned

Fase: FASE 5 — Reward Integration

Milestone: M4.1 — Integração Hunt → Reward Validada

---

# Objetivo

Adicionar ao Vertical Slice a capacidade de encaminhar corretamente o resultado final de uma Hunt concluída para o fluxo de Reward.

---

# Capacidade Entregue

Uma Hunt finalizada disponibiliza seu resultado para o processamento de recompensa sem acoplar responsabilidades entre Hunt e Reward.

---

# Critério de Aceite

- Uma Hunt concluída possui um resultado final válido.
- O resultado pode ser encaminhado ao fluxo de Reward.
- Hunt não aplica recompensa diretamente.
- Reward continua responsável pelo processamento da recompensa.
- Resultados inválidos são rejeitados.
- Hunts canceladas não geram processamento de Reward.
- Nenhuma funcionalidade fora do escopo deste contrato é implementada.
