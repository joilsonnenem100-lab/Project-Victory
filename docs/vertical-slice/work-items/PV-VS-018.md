# PV-VS-018 — Iniciar Hunt com Configuração Válida

Status: Planned

Fase: FASE 1 — First Fun

Milestone: M2.3 — Entrada de Hunt Validada

---

# Objetivo

Adicionar ao Vertical Slice a capacidade de iniciar uma Hunt utilizando uma configuração válida definida pelo sistema.

---

# Capacidade Entregue

Um Character válido consegue iniciar uma Hunt quando uma configuração válida de execução está disponível.

---

# Critério de Aceite

- Uma Hunt somente inicia com configuração válida.
- O Character precisa estar apto para iniciar uma Hunt.
- A criação da Hunt utiliza os dados definidos pela arquitetura oficial.
- Uma Hunt inválida deve ser rejeitada.
- O estado do Character permanece consistente após tentativa inválida.
- Nenhuma funcionalidade fora do escopo deste contrato é implementada.
