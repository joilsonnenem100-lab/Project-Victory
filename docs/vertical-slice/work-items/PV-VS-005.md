# PV-VS-005 — Executar Primeira Hunt

Status: Approved

Tipo: Vertical Slice

# Objetivo

Implementar o primeiro fluxo funcional de execução de Hunt no Project-Victory.

O objetivo deste Vertical Slice é permitir que um Character existente execute uma Hunt simples utilizando as fundações arquiteturais disponíveis.

# Fundamentos utilizados

Utilizar:

- FT-005 — Hunt Execution Foundation.
- Fundação existente do domínio Character.
- Contratos existentes de Combat.
- Contratos existentes de Reward/Progression quando disponíveis.
