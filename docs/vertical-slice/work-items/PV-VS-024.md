# PV-VS-024 — Executar Ação de Combate

Status: Planned

Fase: FASE 4 — Combat Flow Inicial

Milestone: M3.2 — Combat Action Validada

---

# Objetivo

Adicionar ao Vertical Slice a capacidade de executar uma ação dentro de um contexto de combate ativo.

---

# Capacidade Entregue

Um combate iniciado possui uma ação processável que altera seu estado interno conforme as regras oficiais existentes.

---

# Critério de Aceite

- Um Combat Context ativo aceita uma ação de combate válida.
- A ação é processada pelo fluxo oficial de Combat.
- A ação inválida é rejeitada.
- O estado do combate permanece consistente.
- O resultado da ação pode ser utilizado pelo próximo fluxo.
- Nenhuma mecânica avançada de combate é implementada.
