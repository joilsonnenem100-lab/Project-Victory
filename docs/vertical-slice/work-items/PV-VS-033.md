# PV-VS-033 — Aplicar Reward da Hunt

Status: Planned

Fase: FASE 5 — Reward Integration

Milestone: M4.2 — Aplicação de Reward Validada

---

# Objetivo

Adicionar ao Vertical Slice a capacidade de aplicar uma recompensa gerada por uma Hunt concluída através do fluxo oficial de Reward.

---

# Capacidade Entregue

Uma recompensa válida recebida pelo fluxo de Reward pode ser aplicada corretamente mantendo a separação entre Hunt, Reward e Character.

---

# Critério de Aceite

- Uma Reward Request válida pode ser processada.
- O resultado da recompensa é aplicado conforme regras existentes.
- Hunt não aplica recompensa diretamente.
- Reward mantém responsabilidade pelo processamento.
- Recompensas inválidas são rejeitadas.
- O estado do Character permanece consistente.
- Nenhuma funcionalidade fora do escopo deste contrato é implementada.
