# Project-Victory
# First Fun

Status: OFFICIAL

---

# Objetivo

O objetivo do First Fun é validar que o Core Gameplay Loop do Project-Victory é divertido.

Nenhum outro objetivo possui prioridade superior durante o Vertical Slice.

---

# Hipótese

Se um jogador conseguir concluir uma Hunt e desejar iniciar outra espontaneamente, o Core Gameplay Loop foi validado.

---

# Experiência Esperada

O jogador deverá conseguir:

1. Criar uma conta.
2. Entrar no jogo.
3. Criar seu primeiro Character.
4. Iniciar sua primeira Hunt.
5. Acompanhar a Hunt até sua conclusão.
6. Receber o resultado da Hunt.
7. Receber sua recompensa.
8. Evoluir seu personagem.
9. Iniciar imediatamente uma nova Hunt.

---

# O que NÃO estamos tentando validar

Durante o First Fun não faz parte do objetivo validar:

- Interface definitiva.
- Balanceamento final.
- Múltiplas classes.
- Diversidade de monstros.
- Craft.
- Economia.
- Guild.
- PvP.
- Eventos.
- Conteúdo de endgame.

Esses sistemas pertencem às fases posteriores do projeto.

---

# Critério de Sucesso

O First Fun será considerado validado quando um jogador concluir sua primeira Hunt e desejar iniciar uma segunda Hunt sem incentivo externo.

---

# Regra de Ouro

Sempre que surgir uma dúvida de prioridade durante o Vertical Slice, a decisão deverá considerar apenas uma pergunta:

"Esta decisão aproxima o jogador da segunda Hunt?"
