# Vertical Slice
# Acceptance Criteria

Status: OFFICIAL

---

# Objetivo

Padronizar os critérios de aceite de todos os Contratos PV-VS.

Este documento evita interpretações diferentes sobre quando uma funcionalidade pode ser considerada concluída.

---

# Critérios Gerais

Todo Contrato PV-VS somente poderá ser considerado concluído quando:

- A capacidade descrita no contrato estiver disponível.
- O comportamento respeitar a documentação oficial.
- O escopo do contrato tiver sido respeitado.
- Não houver implementação de funcionalidades fora do escopo.
- A validação manual do contrato for executada com sucesso.

---

# Definição de Concluído

Um Contrato PV-VS estará concluído somente quando:

- Implementação finalizada.
- Gate Técnico aprovado.
- GitHub atualizado.

---

# Regra

Um contrato nunca será aprovado parcialmente.

O resultado possível é apenas:

- Aprovado
- Ajustes Necessários
