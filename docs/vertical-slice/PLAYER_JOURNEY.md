# Project-Victory
# Player Journey

Status: OFFICIAL

---

# Objetivo

Definir a jornada completa que um jogador percorre durante o Vertical Slice.

Esta jornada representa toda a experiência que deverá ser validada antes do encerramento do Vertical Slice.

---

# Jornada

1. Criar uma conta.

↓

2. Realizar login.

↓

3. Criar o primeiro Character.

↓

4. Entrar no jogo.

↓

5. Preparar a primeira Hunt.

↓

6. Executar a Hunt.

↓

7. Receber o resultado.

↓

8. Receber experiência.

↓

9. Evoluir o Character (quando aplicável).

↓

10. Iniciar imediatamente uma nova Hunt.

---

# Objetivo

Ao concluir essa jornada o jogador deverá compreender naturalmente qual é o ciclo principal do jogo.

---

# Critério de Sucesso

O Player Journey será considerado validado quando um jogador conseguir percorrer todas as etapas sem auxílio externo e desejar continuar jogando.

---

# Princípios

- Cada etapa deve possuir um objetivo claro.
- Nenhuma etapa deve gerar dúvida sobre o próximo passo.
- O fluxo deve ser contínuo.
- O jogador nunca deve ficar sem uma ação disponível.

---

# Fora do Escopo

Não fazem parte desta jornada:

- PvP
- Guild
- Craft
- Marketplace
- Eventos
- Sistema Social
- Conteúdo Endgame
- Funcionalidades Premium
