# Project-Victory
# Character Progression Specification

Status: OFFICIAL

---

# Objetivo

Definir a progressão mínima do Character durante o Vertical Slice.

O objetivo não é validar balanceamento, mas validar que a progressão incentiva o jogador a realizar novas Hunts.

---

# Progressão

Ao concluir uma Hunt o Character poderá receber:

- Experiência
- Níveis

---

# Evolução

Ao subir de nível:

- O novo nível deve ser informado ao jogador.
- A experiência necessária para o próximo nível deve ser exibida.

---

# Escopo

Durante o Vertical Slice a progressão será limitada a:

- Level
- Experience

Nenhum outro sistema de progressão faz parte deste documento.

---

# Fora do Escopo

- Skills
- Atributos
- Talent Tree
- Promotions
- Blessings
- Rebirth
- Mastery
- Achievements

---

# Critério de Sucesso

O jogador deve perceber claramente que ficou mais forte após realizar Hunts consecutivas.

A progressão deve incentivar imediatamente uma nova Hunt.
