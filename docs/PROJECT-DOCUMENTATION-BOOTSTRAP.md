# Regras

A documentação oficial é a única fonte de verdade.

Nunca assumir arquivos, classes ou sistemas inexistentes.

Nunca substituir uma implementação existente sem verificar impacto.

Nunca remover comportamento validado para adicionar uma nova funcionalidade.

---

# Antes de implementar

Confirmar:

- arquivos envolvidos
- arquitetura existente
- contrato relacionado
- impacto nos sistemas atuais

---

# Durante implementação

Alterar somente arquivos necessários.

Preservar funcionalidades existentes.

Validar compilação e comportamento.

---

# Após implementação

Atualizar:

- estado atual quando necessário
- documentação relacionada
- status do contrato
