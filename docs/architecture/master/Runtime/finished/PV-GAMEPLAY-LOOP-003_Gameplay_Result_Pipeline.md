# Gameplay Result Pipeline

## Objetivo

Criar uma padronização para resultados de gameplay.

## Fluxo esperado

Gameplay Execution

↓

Result

↓

Consequências

## Exemplos

- Victory
- Defeat
- Cancelled

## Responsabilidade

Transportar o resultado entre sistemas.

## Não implementar

- Fórmulas de recompensa
- XP
- Balanceamento

## Critério de aceitação

Um resultado de gameplay pode ser processado por etapas posteriores.
