# PV-RUNTIME-002 Runtime Persistence Foundation

## Objetivo
Criar persistência oficial do Runtime.

## Fluxo
Runtime
↓
Database
↓
Recovery

## Persistir
- RuntimeId
- CharacterId
- Estado necessário da sessão

## Não alterar
Combat
Loot
Reward
Inventory

## Aceitação
Runtime criado, salvo e recuperado.
