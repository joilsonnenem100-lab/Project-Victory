# Location Content Definition

## Objetivo
Criar a definição estrutural dos conteúdos que podem existir dentro de uma Location.

## Fluxo
World
↓
Region
↓
Location
↓
Content

## Responsabilidade
Representar conteúdos disponíveis em uma localização.

Exemplos:
- Hunt disponível
- Evento possível
- Ponto de interação

## Não implementar
- Monstros
- Skills
- Balanceamento
- Recompensas
