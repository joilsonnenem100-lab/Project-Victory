# Engineering Autonomy Rules


## Complementação Técnica

A Engenharia pode completar lacunas técnicas quando:

- a estrutura já existe;
- segue padrões existentes;
- não cria novos conceitos;
- não altera arquitetura.


## Mudança Arquitetural

Requer decisão arquitetural quando:

- cria novo sistema;
- altera responsabilidades;
- muda fluxo principal;
- cria novo conceito.


## Hierarquia Documental

1. Contratos ativos aprovados

2. Decisões arquiteturais

3. docs/architecture/master

4. knowledge-base

5. developer-guide

6. documentos experimentais


## Regra de Continuidade

A ausência de uma implementação não significa ausência de arquitetura.

A Engenharia deve investigar e complementar quando a alteração for técnica.

Bloqueio somente ocorre quando houver impacto arquitetural.
