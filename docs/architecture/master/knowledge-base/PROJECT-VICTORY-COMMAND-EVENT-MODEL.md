# PROJECT-VICTORY --- COMMAND AND EVENT MODEL

## Commands

Representam intenção de alterar estado.

Exemplos:

-   CreateCharacterCommand
-   StartHuntCommand
-   AttackCommand
-   EquipItemCommand

------------------------------------------------------------------------

## Events

Representam fatos ocorridos.

Exemplos:

-   CharacterCreatedEvent
-   CombatCompletedEvent
-   RewardGrantedEvent
-   LevelUpEvent

------------------------------------------------------------------------

## Objetivo futuro

Reduzir acoplamento entre sistemas.
