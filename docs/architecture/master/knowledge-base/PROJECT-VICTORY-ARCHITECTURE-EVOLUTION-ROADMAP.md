# PROJECT-VICTORY --- ARCHITECTURE EVOLUTION ROADMAP

## Objetivo

Registrar a evolução arquitetural do Project-Victory separando fundação
existente, evolução planejada e visão futura.

## Fase 1 --- Player Foundation

Status: Oficial

Inclui:

-   Account
-   Authentication
-   Character
-   Persistence

Objetivo:

Criar identidade persistente do jogador.

------------------------------------------------------------------------

## Fase 2 --- Gameplay Foundation

Status: Fundação criada

Inclui:

-   Hunt Foundation
-   Monster Foundation
-   Combat Foundation
-   Reward Foundation
-   Progression Foundation

Objetivo:

Criar o primeiro ciclo jogável.

------------------------------------------------------------------------

## Fase 3 --- Runtime Evolution

Status: Evolução arquitetural

Inclui conceitos:

-   Game Session
-   Runtime Environment
-   Runtime State
-   Runtime Coordinator
-   Hunt Loop

Objetivo:

Transformar ações isoladas em experiência contínua.
