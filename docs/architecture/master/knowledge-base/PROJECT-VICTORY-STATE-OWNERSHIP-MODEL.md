# PROJECT-VICTORY --- STATE OWNERSHIP MODEL

## Princípio

Cada estado possui um dono responsável.

## Account State

Dono:

Account Aggregate

------------------------------------------------------------------------

## Character State

Dono:

Character Aggregate

Representa:

Quem o personagem é.

------------------------------------------------------------------------

## Runtime State

Dono:

Runtime Layer

Representa:

O que está acontecendo agora.

------------------------------------------------------------------------

## Hunt State

Dono:

Hunt Runtime

Representa:

Execução de uma atividade.

------------------------------------------------------------------------

## Combat State

Dono:

Combat System

Representa:

Estado da resolução de combate.

------------------------------------------------------------------------

## World State

Dono:

World System

Representa:

Estado compartilhado do mundo.
