# PROJECT-VICTORY --- PERSISTENCE STRATEGY

## Estado Permanente

Salvar:

-   Account
-   Character
-   Inventory
-   Skills

------------------------------------------------------------------------

## Estado Semi-Permanente

Salvar:

-   Hunt Session
-   Quest Progress
-   World Changes

------------------------------------------------------------------------

## Estado Temporário

Normalmente não persistir diretamente:

-   cálculos de combate;
-   estados momentâneos;
-   dados de execução curta.

------------------------------------------------------------------------

## Objetivo

Definir quando e como estados importantes sobrevivem.
