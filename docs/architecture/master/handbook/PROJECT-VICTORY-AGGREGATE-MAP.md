# PROJECT-VICTORY --- AGGREGATE MAP

## Account Aggregate

Responsável por:

-   identidade;
-   autenticação;
-   segurança.

------------------------------------------------------------------------

## Character Aggregate

Responsável por:

-   identidade do personagem;
-   experiência;
-   progressão;
-   habilidades futuras.

Não controla:

-   combate;
-   Hunt ativa.

------------------------------------------------------------------------

## Hunt Aggregate (Conceitual)

Responsável por:

-   sessão;
-   encontros;
-   execução da atividade.

------------------------------------------------------------------------

## Combat Context

Responsável por:

-   resolução;
-   resultado da batalha.
