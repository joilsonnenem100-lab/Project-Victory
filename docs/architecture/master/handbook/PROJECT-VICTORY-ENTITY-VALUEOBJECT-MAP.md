# PROJECT-VICTORY --- ENTITY VALUE OBJECT MAP

## Entity

Possui identidade própria.

Exemplos:

-   Character
-   Account
-   MonsterInstance
-   HuntSession

------------------------------------------------------------------------

## Value Object

Representa valores.

Exemplos:

-   Stats
-   Damage
-   Experience
-   Position

------------------------------------------------------------------------

## Aggregate Root

Controla regras internas.

Exemplos:

-   Account
-   Character
