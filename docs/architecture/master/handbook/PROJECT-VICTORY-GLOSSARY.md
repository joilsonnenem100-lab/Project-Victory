# PROJECT-VICTORY --- GLOSSARY

## Aggregate

Unidade de domínio com regras próprias.

## Runtime

Ambiente de execução de gameplay.

## Runtime State

Estado atual de uma atividade.

## Definition

Modelo de conteúdo.

## Instance

Objeto criado durante execução.

## Encounter

Encontro de gameplay.

## Context

Informações necessárias para execução.

## Event

Fato ocorrido no sistema.
