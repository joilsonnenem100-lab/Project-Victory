# PROJECT-VICTORY --- Attribute System Foundation

## Status

Documento de consolidação das decisões de Product Owner relacionadas ao
sistema de atributos do personagem.

Este documento define a fundação conceitual entre:

Character

↓

Attributes

↓

Skills

↓

Progression

↓

Combat

------------------------------------------------------------------------

# 1. Objetivo do Sistema de Attributes

Attributes representam características fundamentais do personagem.

Eles não substituem Skills.

A relação definida:

Attributes

↓

Valores derivados

↓

Gameplay

------------------------------------------------------------------------

Exemplo:

Atributos determinam potencial.

Skills determinam especialização.

------------------------------------------------------------------------

# 2. Modelo Geral

Decisão:

Modelo híbrido.

O personagem possui:

-   atributos base;
-   valores derivados;
-   habilidades de combate.

Os atributos fazem parte da identidade do personagem.

------------------------------------------------------------------------

# 3. Distribuição de Pontos

Decisão:

O jogador não distribui pontos ao subir de nível.

A evolução é definida pela classe e progressão do personagem.

Fluxo:

Level Up

↓

Classe aplica crescimento

↓

Character evolui

------------------------------------------------------------------------

# 4. Skills Principais de Combate

As especializações principais são representadas por Skills.

------------------------------------------------------------------------

# Sword / Axe / Club Fighting

Responsabilidade:

Determinam:

-   força de ataque;
-   precisão;
-   eficiência com armas corpo a corpo.

Especialização principal:

Knight.

------------------------------------------------------------------------

# Distance Fighting

Responsabilidade:

Define:

-   força de ataques à distância;
-   precisão com armas de distância.

Especialização principal:

Paladin.

------------------------------------------------------------------------

# Magic Level (ML)

Responsabilidade:

Representa potencial mágico.

Impacta:

-   dano mágico;
-   cura;
-   runas ofensivas;
-   eficiência de magias.

Classes principais:

-   Sorcerer;
-   Druid.

Também possui importância para:

-   Knight;
-   Paladin.

------------------------------------------------------------------------

# Shielding

Responsabilidade:

Aumenta:

-   defesa;
-   capacidade de bloquear ataques;
-   eficiência utilizando escudos.

------------------------------------------------------------------------

# Fist Fighting

Responsabilidade:

Especialização de combate desarmado.

Classe principal:

Monk.

------------------------------------------------------------------------

# 5. Exibição ao Jogador

Decisão:

Atributos e informações de evolução devem ser visíveis.

O jogador acompanha:

-   evolução;
-   poder;
-   progresso.

------------------------------------------------------------------------

# 6. Equipamentos e Atributos

Decisão:

Equipamentos podem modificar atributos.

Exemplo conceitual:

Armadura:

↓

mais defesa/resistência

Arma:

↓

maior capacidade ofensiva

------------------------------------------------------------------------

# 7. Buffs e Modificadores Temporários

Decisão:

Buffs temporários podem alterar atributos.

Exemplos futuros:

-   poções;
-   magias;
-   efeitos temporários;
-   estados especiais.

------------------------------------------------------------------------

# 8. Diferença Entre Classes

Decisão:

As classes não possuem atributos internos iniciais diferentes.

A diferenciação inicial ocorre por:

-   HP;
-   Mana;
-   crescimento por level;
-   Skills;
-   progressão.

------------------------------------------------------------------------

# 9. Redução de Atributos

Decisão:

Atributos podem ser reduzidos através de efeitos temporários.

Exemplos futuros:

-   debuffs;
-   maldições;
-   efeitos negativos.

Não existe redução permanente definida.

------------------------------------------------------------------------

# 10. Relação com Character

Character possui:

-   atributos;
-   skills;
-   progresso.

O sistema de atributos pertence à evolução do personagem.

------------------------------------------------------------------------

# 11. Estado do Bloco

Definido:

-   modelo híbrido de atributos;
-   ausência de distribuição manual de pontos;

-   Magic Level;
-   Shielding;

-   influência de equipamentos;
-   buffs temporários;
-   diferenciação de classes.
