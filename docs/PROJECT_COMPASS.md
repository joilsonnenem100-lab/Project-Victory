Project Victory Compass
Visão do Jogo

Project-Victory é um MMORPG moderno inspirado nos princípios que tornaram os RPGs clássicos memoráveis, preservando sua identidade enquanto elimina atividades repetitivas desnecessárias.

O objetivo do jogo é proporcionar progressão contínua, decisões estratégicas e evolução de longo prazo, permitindo que o jogador invista seu tempo na construção do personagem, e não na execução repetitiva de tarefas.

Toda evolução deve ser conquistada através das mecânicas do próprio jogo.

Filosofia do Projeto

Todo sistema do Project-Victory deve seguir os seguintes princípios:

Simplicidade antes de complexidade.
Clareza antes de quantidade.
Consistência antes de novidade.
Automação quando ela elimina repetição, nunca quando elimina estratégia.
Sistemas devem cooperar entre si sem criar dependências desnecessárias.
O jogador deve tomar decisões; a Engine deve executar essas decisões de forma previsível.
Novas funcionalidades devem reutilizar a arquitetura existente sempre que possível.
O crescimento do projeto nunca deve comprometer sua simplicidade.
Core Gameplay Loop

O ciclo principal do jogo é:

Planejar → Preparar → Executar → Evoluir → Planejar novamente

O jogador define sua estratégia.

A Engine executa essa estratégia.

Os resultados obtidos influenciam a próxima decisão do jogador, criando um ciclo contínuo de evolução.

Todo novo sistema deve fortalecer esse ciclo, nunca substituí-lo.

Regra de Ouro

Toda decisão do Project-Victory deve responder positivamente às seguintes perguntas:

Esta decisão torna o jogo mais simples de compreender?
Esta decisão fortalece a progressão de longo prazo?
Esta decisão respeita a liberdade estratégica do jogador?
Esta decisão preserva a consistência do produto?
Esta decisão poderá continuar fazendo sentido daqui a muitos anos?

Se a resposta para qualquer uma dessas perguntas for negativa, a decisão deve ser reavaliada antes de seguir para Arquitetura, Domínio ou Implementação
