# PV-ART-002 — Asset Specification Template

Todo asset deve possuir:

- Código
- Nome
- Local de aplicação
- Objetivo
- Experiência desejada
- Direção visual
- Elementos obrigatórios
- Elementos proibidos
- Referências
- Especificação técnica
- Aprovação
- Histórico

Nenhuma arte deve ser criada sem especificação.
