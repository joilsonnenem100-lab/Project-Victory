# PV-ART-001 — Interface Art Language

## Filosofia

A interface é um artefato pertencente ao mundo.

## Direção

Mistura:
- Castelo.
- Floresta.
- Pedra antiga.
- Elementos naturais.

## Princípios

A interface não deve parecer:
- Aplicativo.
- MMO genérico.
- Excesso de números.

## Informações

Devem representar:
- Conquistas.
- Jornada.
- Evolução.

## Cores

Base:
- Azul profundo.

Destaque:
- Dourado como conquista.
