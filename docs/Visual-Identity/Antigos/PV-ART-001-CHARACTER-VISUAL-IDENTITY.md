# PV-ART-001 — Character Visual Identity

## Identidade

O personagem é:

- Um aventureiro comum começando sua jornada.
- Um desconhecido em um mundo enorme.

## Arquétipo

- Explorador.
- Sobrevivente.

## Objetivo emocional

O jogador deve sentir:

"Estou criando uma futura lenda."

## Evolução

Deve ser percebida por:
- Presença.
- Reconhecimento.
- Aparência.
- Equipamentos.

## Evitar

- Herói genérico.
- Cópia de outro jogo.
- Personagem infantil.
- Personagem sem importância.
