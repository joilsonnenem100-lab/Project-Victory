# PV-ART-001 — Asset Production Rules

## Fluxo obrigatório

Necessidade visual

↓

Documento

↓

Aprovação

↓

Produção

↓

Validação

↓

Aplicação

## Regras

Assets devem ser classificados por função:
- Backgrounds
- Characters
- Environments
- UI
- Icons
- Concept Art

## Nomenclatura

Usar padrão obrigatório.

Exemplo:
login_world_background_v01.png

## Gerenciamento

Buscar ferramenta visual para facilitar troca e organização dos assets.

## Critério principal

Identidade PROJECT-VICTORY antes de beleza visual.
