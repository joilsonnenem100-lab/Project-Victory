# Objetivo da Fase

A Fase 3 tem como objetivo evoluir a fundação criada nas fases anteriores para uma experiência de jogo mais completa, mantendo os contratos arquiteturais estabelecidos.

A Fase 2 entregou:

- mundo inicial;
- conteúdo inicial de Hunt;
- integração Combat;
- progressão real;
- experiência do jogador;
- persistência inicial.
