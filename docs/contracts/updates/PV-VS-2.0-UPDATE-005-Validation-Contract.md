# PV-VS-2.0-UPDATE-005 — Critérios de Aceite

O contrato será aceito quando:

- Account sem Character consegue criar um Character.
- Nome do Character é persistido.
- Character fica associado à Account correta.
- Entrada no mundo continua funcionando.
- Hunt, Combat, Reward e Progression permanecem sem regressão.

## Restrições

Não implementar:

- Classes.
- Skills.
- Attributes.
- Equipamentos.
- Inventário.
- Economia.
- Sistemas futuros.

## Entrega Engenharia

Enviar:

- arquivos alterados;
- build;
- testes;
- evidências funcionais.
