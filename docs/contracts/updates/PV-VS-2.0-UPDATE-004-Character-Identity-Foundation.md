# PV-VS-2.0-UPDATE-004 — Character Identity Foundation

## Objetivo

Evoluir o Character de uma estrutura funcional para uma identidade persistente do jogador.

## Contexto atual

O Character atualmente participa do loop:

Character
↓
Hunt
↓
Combat
↓
Reward
↓
Progression
↓
Persistence

Este ciclo deve permanecer funcionando.

## Objetivo do ciclo

Adicionar a primeira camada de identidade do Character.

## Escopo

- Identidade do Character.
- Nome do Character.
- Exibição da identidade no Player Entry.
- Persistência dos dados.

## Não implementar

- Classes.
- Raças.
- Aparência.
- Customização visual.
- Skills.
- Equipamentos.
- Inventário.
- Sistemas futuros.
