# PV-VS-2.0-UPDATE-005 — Character Creation Experience

## Objetivo

Permitir que uma Account sem Character consiga criar seu primeiro Character pela experiência web.

## Contexto atual

Fluxo existente:

Account
↓
Login
↓
Character
↓
Player Entry
↓
Hunt
↓
Combat
↓
Reward
↓
Progression

Este ciclo deve permanecer funcionando.

## Novo fluxo esperado

Account
↓
Login
↓
Verificação de Character
↓
Character Creation
↓
Persistência
↓
Player Entry

## Escopo

- Criar experiência de criação de Character.
- Permitir definição do Nome.
- Persistir identidade inicial.
- Integrar com fluxo existente de entrada no mundo.

## Não implementar

- Classes.
- Raças.
- Aparência.
- Customização visual.
- Attributes.
- Skills.
- Equipamentos.
- Inventário.
- Economia.
- Balanceamento.
