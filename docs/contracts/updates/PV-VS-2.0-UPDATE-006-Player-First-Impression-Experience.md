# PV-VS-2.0-UPDATE-006 — Player First Impression Experience

## Objetivo

Transformar o primeiro contato do jogador com o PROJECT-VICTORY em uma experiência visual de entrada no mundo.

O sistema atual possui o fluxo funcional completo:

Account
↓
Login
↓
Character Creation
↓
Player Entry
↓
Gameplay

Este ciclo tem como objetivo melhorar a experiência inicial sem alterar regras de negócio.

## Visão

Evoluir de:

"Aplicação funcional"

para:

"Entrada no mundo do Project-Victory"

## Escopo

- Melhorar experiência visual do Login.
- Criar identidade visual inicial.
- Melhorar transição entre autenticação e entrada no jogo.
- Preparar componentes visuais reutilizáveis.

## Restrições

Não alterar:

- Account Domain.
- Authentication Logic.
- JWT.
- Character Domain.
- Hunt.
- Combat.
- Reward.
- Progression.
- Persistence.

Não implementar:

- Classes.
- Raças.
- Skills.
- Equipamentos.
- Inventário.
- Economia.
