# PV-VS-2.0-UPDATE-004 — Critérios de Aceite

O ciclo será aceito quando:

- Character possuir identidade persistente.
- Nome do Character estiver disponível na experiência do jogador.
- Dados existentes de progressão continuarem funcionando.
- Persistência continuar válida.
- Hunt, Combat, Reward e Progression não sofrerem regressão.

## Restrições

Não implementar:

- Classes.
- Skills.
- Equipamentos.
- Inventário.
- Economia.
- Novos sistemas de gameplay.

## Entrega Engenharia

Enviar:

- arquivos alterados;
- build;
- testes;
- evidências funcionais.
