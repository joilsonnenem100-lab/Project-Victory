# PV-VS-FE-001 — Frontend Game Experience Foundation

## Objetivo

Reestruturar o frontend do Project-Victory para uma experiência inicial de jogo Idle/MMORPG simples, organizada e funcional.

Escopo exclusivo de frontend.

Não alterar regras de gameplay ou domínio.

## Fluxo principal

Login -> Character Selection -> Game Interface -> Hunt Interface

## Escopo

- Tela Login
- Character Selection
- Game Interface
- Hunt Interface
- Tema visual
- Navegação

## Fora de escopo

- Item System
- Inventory funcional
- Equipment
- Novas regras de combate
- Backend novo
- Persistência nova

## Critérios

- Navegação funcionando
- Botões funcionais
- Telas consistentes
- Build frontend funcionando
