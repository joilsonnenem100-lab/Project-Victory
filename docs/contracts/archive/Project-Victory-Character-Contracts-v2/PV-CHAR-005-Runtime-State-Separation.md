# PV-CHAR-005 --- Runtime State Separation

## Objetivo

Separar estado permanente do Character de estados temporários de
gameplay.

## Escopo

Definir separação entre:

Estado permanente:

-   Level;
-   Experience;
-   Base Stats;
-   Skills.

Estado temporário:

-   Current HP;
-   Current Mana;
-   Estados de combate.

## Fora do escopo

-   Novo sistema de combate;
-   Alterações amplas de arquitetura.
