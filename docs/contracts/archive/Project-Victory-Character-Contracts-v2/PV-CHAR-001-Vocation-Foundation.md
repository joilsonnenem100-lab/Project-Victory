# PV-CHAR-001 --- Vocation Foundation

## Objetivo

Adicionar a fundação de Vocação do Character.

## Escopo

Implementar:

-   Vocation no Character;
-   Knight;
-   Paladin;
-   Sorcerer;
-   Druid;
-   Monk.

## Fora do escopo

-   Skills completas;
-   Combat avançado;
-   Equipment;
-   Inventory.

## Critérios de Aceitação

-   Character possui uma Vocation definida.
-   Vocation permanece associada ao Character.
-   Fluxos existentes continuam funcionando.
