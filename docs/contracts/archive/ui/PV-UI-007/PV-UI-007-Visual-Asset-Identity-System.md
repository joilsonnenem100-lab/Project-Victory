# PV-UI-007 — Visual Asset Identity System

## Objetivo

Definir a identidade visual dos assets utilizados nas experiências iniciais do PROJECT-VICTORY.

PV-UI-006 criou a fundação técnica do Background Identity System.
PV-UI-007 define a linguagem visual aplicada sobre essa fundação.

## Escopo

Inclui:

- Direção artística dos assets.
- Organização de imagens.
- Backgrounds oficiais.
- Aplicação visual por tela.

Não inclui:

- Sistemas cosméticos.
- Personalização pelo jogador.
- Novas mecânicas.
