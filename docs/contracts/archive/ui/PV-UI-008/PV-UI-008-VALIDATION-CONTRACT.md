# PV-UI-008 — Validation Contract

Validar:

- Assets organizados.
- Referências centralizadas.
- Facilidade de manutenção.
- Compatibilidade com UI existente.
- Build aprovado.

Não alterar:

- Backend.
- API.
- Domain.
- Gameplay Logic.

Não implementar:

- Cosméticos.
- Skins.
- Personalização visual pelo jogador.
- Novos sistemas de gameplay.
