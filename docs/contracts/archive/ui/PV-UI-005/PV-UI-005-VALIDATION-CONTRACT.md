# PV-UI-005 — Validation Contract

## Critérios de aceite

Aceitar quando:

- Layout responsivo funcionando.
- Componentes adaptáveis.
- Identidade visual preservada.
- Fluxos mantidos.
- Build aprovado.

## Fluxo obrigatório

Login
↓
Character
↓
Player Interface
↓
Gameplay Presentation
↓
Hunt
↓
Combat
↓
Reward
↓
Progression

## Restrições

Não aceitar:

- Alterações de gameplay.
- Alterações de domínio.
- Novos sistemas.

## Entrega Engenharia

Enviar:

- Arquivos alterados.
- Resoluções testadas.
- Build.
- Evidências funcionais.
