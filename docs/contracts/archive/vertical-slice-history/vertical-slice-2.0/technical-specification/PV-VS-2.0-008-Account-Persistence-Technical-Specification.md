# PV-VS-2.0-008 — Account Persistence Technical Specification

## Objetivo
Definir a especificação técnica de persistência da Account dentro do Vertical Slice 2.0.

## Escopo
- Estrutura persistente da Account.
- Identificação única.
- Armazenamento seguro dos dados necessários.
- Recuperação após reinício.

## Fora do escopo
- Recuperação de senha.
- Confirmação de email.
- Sistemas sociais.

## Critérios de aceite
Account criada permanece disponível após reinicialização do sistema.
