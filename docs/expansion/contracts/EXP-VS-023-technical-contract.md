# EXP-VS-023 — Technical Contract

## Nome

Criar Combat Resolution Result

---

# Objetivo Técnico

Criar uma representação formal do resultado produzido após a resolução de combate.

Este PV-VS cria somente a saída estruturada do combate.

Não processa recompensas.

---

# Contexto Arquitetural

Combat produz um resultado.

Outros domínios consomem este resultado conforme suas responsabilidades.
