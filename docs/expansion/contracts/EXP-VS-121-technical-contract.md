# EXP-VS-121 — Technical Contract

## Nome

Playtest Feedback Capture

---

# Objetivo Técnico

Criar a estrutura inicial para captura organizada de feedback durante o primeiro teste interno do Vertical Slice.

Este PV-VS não cria sistema de analytics, telemetria ou coleta automática.

O objetivo é permitir organização e rastreabilidade dos resultados encontrados durante testes.
