# EXP-VS-022 — Technical Contract

## Nome

Criar Combat Rule Definition

---

# Objetivo Técnico

Criar uma estrutura inicial para representar regras utilizadas durante a resolução de combate.

Este PV-VS cria somente a definição das regras de combate.

Não implementa sistemas avançados de combate.

---

# Contexto Arquitetural

Combat deve possuir responsabilidade própria sobre a resolução do confronto.

As regras utilizadas durante o combate pertencem ao domínio Combat.
